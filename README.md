# Booking Revenue Analytics Dashboard (Excel)

## Project Overview

This project analyzes booking and revenue data using Excel to uncover key business trends, profitability drivers, and customer behavior patterns. The goal is to transform raw booking data into actionable insights through interactive dashboards and KPI reporting.

The dashboard enables stakeholders to monitor revenue performance, identify high-performing locations, and evaluate pricing and discount strategies.

---

## Business Objectives

- Analyze booking and revenue trends across cities and categories
- Identify top-performing locations and revenue drivers
- Evaluate the impact of pricing, discounts, and stay duration
- Monitor key financial KPIs for decision-making

---

## Dataset Description

The dataset contains 10,000+ booking records including:

- Booking ID and customer details
- City and category information
- Revenue and pricing data
- Discount and rent values
- Stay duration and booking patterns

---

## Tools & Techniques Used

- **Microsoft Excel**
  - Pivot Tables
  - Advanced formulas
  - Charts and dashboard visualization
- **Power Query**
  - Data cleaning and transformation
- **Data Analysis Techniques**
  - Exploratory Data Analysis (EDA)
  - KPI tracking
  - Trend and segmentation analysis

---

## Key Features of the Dashboard

- Interactive revenue and booking performance dashboard
- KPI tracking for total revenue, bookings, and average values
- City-wise and category-wise performance analysis
- Visual insights into discount and pricing patterns
- Profitability trend visualization

---

## Key Insights

- Identified high-performing cities contributing the majority of revenue
- Revealed pricing and discount patterns affecting profitability
- Highlighted booking trends across categories and time periods
- Provided actionable insights for improving revenue performance
